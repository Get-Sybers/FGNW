FGNW-universe data used to reskin this blueprint (see `docs/range-design.md`). Two kinds of file live
here: **source data** (hand/LLM-curated, edited directly) and **generated data** (produced from
a source file by a one-off script, regenerate rather than hand-edit).

| `AD/characters.csv` | source | `ad/NARUTO/data/config.json` (regenerated by a scratch transform script - see docs/range-design.md) | 198 characters: `acdb_id, sAMAccountName, givenName, sn, displayName, gender, apparentAge, role, department, village, title, groups, manager, description, quote, all_quotes, quote_count`. `village` = home village, `department` = current affiliation - where they differ (e.g. Orochimaru: village=Leaf, department=Sound Village) the character is a defector/missing-nin. `.edo`/`.sage` suffixed `sAMAccountName`s are Edo Tensei/Sage-mode variants of an existing character and are filtered out during generation, not separate identities. **Exception**: `fire.daimyo` (populating `fire.ninja` alongside `shijimi`) has a blank `acdb_id` — not found in ACDB, flagged inline in its `description`. Every other row (including `shijimi`, id `79733`) is ACDB-sourced per `credits.md`. |

| `OWA/user-inboxes.yml` | **generated** from `OWA/email-content.csv` + `ghosts/email-relationships.yml`, **+14 hand-authored exceptions**, seeded by `ansible/roles/fgnw_exchange_seed_mail` (invoked by `ansible/FGNW-exchange-seed-mail.yml`, real `Send-MailMessage` once Exchange install succeeds — the active path) | Per-user inbox data: `user_inboxes[sAMAccountName]` = list of `{from_name, from_address, subject, body}`. This is the literal answer to "which characters should be emailing each other" — every edge is a real, inspectable AD relationship, not a random pairing. |

Both `filesystem/village-folders.yml` and `www/village-bookmarks.yml` were produced by short,
one-off Python scripts (parse the source file, dump YAML) run from the repo root against this
directory - there's no committed script since they're not expected to change often. If you edit
`documents.txt` or `FGNW_character_websites.csv`, regenerate the corresponding `.yml` by hand
or with a fresh throwaway script rather than hand-patching the generated file, or the two will
drift.
